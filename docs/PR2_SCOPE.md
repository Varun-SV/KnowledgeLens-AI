# v0.3 persistence and provider foundation

This branch is roadmap PR 2 of 4. It establishes PostgreSQL-backed application metadata, a local content-addressed blob store, persistent provider profiles, secure credential storage, model discovery, bootstrap administration primitives, and OIDC configuration foundations while preserving the existing portable NetworkX/JSON workflow.

Docling/multimodal ingestion, resumable large-document processing, scalable graph materialization, and production authentication remain in the following roadmap PRs.
